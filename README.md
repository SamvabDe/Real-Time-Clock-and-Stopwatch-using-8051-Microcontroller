# Real-Time-Clock-and-Stopwatch-using-8051-Microcontroller
Real-Time Clock and Stopwatch using the 8051 microcontroller, programmed in Assembly using Keil µVision. Features timer interrupts, ISR-based timekeeping, common-cathode 7-segment displays interfaced via 8255 PPI, and clock/stopwatch modes with start, stop, and reset controls.
